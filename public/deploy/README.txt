Merlin Wi-Fi deploy folder
==========================

1. Browser test (no install):
   http://<your-server>:3000/deploy/ce-wifi-test.html

2. Deploy hub:
   http://<your-server>:3000/deploy/

3. Native test app (.cab):
   After building on PC, copy MerlinInventoryTest.cab into THIS folder.
   Then open http://<server>:3000/deploy/ on the Merlin and tap Install.

4. NAS alternative:
   Copy the same .cab to \\your-nas\share\deploy\
   On Merlin: File Explorer -> enter UNC path -> tap .cab
